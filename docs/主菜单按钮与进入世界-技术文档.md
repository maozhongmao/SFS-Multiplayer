# SFS 1.6 PC：主菜单新增按钮并进入世界

适用：SFS 1.6 PC + ModLoader + Harmony。

目标：在 Home_PC 的 Buttons 节点下新增按钮；点击后进入世界。

## 调用链

```text
Home_PC 加载
 -> SceneHelper.OnHomeSceneLoaded
 -> Instantiate("Play Button")
 -> 改文字、重绑 clickEvent
 -> WorldEntry.Open()
 -> WorldBaseManager.EnterWorld(null, settings, Base.sceneLoader.LoadHubScene)
 -> 进入 Hub_PC
```

联机按钮的真实实现：
Main.AddMultiplayerButton() 克隆 Play Button，点击调用 JoinMenu.OpenMenu()。

## MainMenuButtonMod.cs

```csharp
using System;
using ModLoader;
using ModLoader.Helpers;
using SFS.Audio;
using SFS.UI;
using UnityEngine;

namespace MyMod
{
    public class MainMenuButtonMod : Mod
    {
        public static MainMenuButtonMod main;

        public override string ModNameID => "my-main-menu-button";
        public override string DisplayName => "My Main Menu Button";
        public override string Author => "your-name";
        public override string ModVersion => "1.0.0";
        public override string MinimumGameVersionNecessary => "1.6.00.16";
        public override string Description => "Adds a custom main-menu button.";

        public override void Load()
        {
            main = this;
            SceneHelper.OnHomeSceneLoaded += AddMainMenuButton;
            AddMainMenuButton();
        }

        public static void AddMainMenuButton()
        {
            if (GameObject.Find("MyMod - Button") != null) return;

            Transform buttons = GameObject.Find("Buttons")?.transform;
            GameObject playButton = GameObject.Find("Play Button");
            if (buttons == null || playButton == null) return;

            GameObject clone = UnityEngine.Object.Instantiate(playButton, buttons, true);
            clone.name = "MyMod - Button";

            RectTransform cloneRect = clone.GetComponent<RectTransform>();
            RectTransform playRect = playButton.GetComponent<RectTransform>();
            cloneRect.SetSiblingIndex(playRect.GetSiblingIndex() + 1);

            TranslationSelector selector = clone.GetComponent<TranslationSelector>();
            if (selector != null) UnityEngine.Object.Destroy(selector);

            TextAdapter text = clone.GetComponentInChildren<TextAdapter>();
            if (text != null) text.Text = "My World";

            ButtonPC button = clone.GetComponent<ButtonPC>();
            button.holdEvent = new HoldUnityEvent();
            button.clickEvent = new ClickUnityEvent();
            button.clickEvent.AddListener(delegate
            {
                SoundPlayer.main.clickSound.Play();
                WorldEntry.Open();

                // 如果要完全复用联机入口，改成：
                // MultiplayerSFS.Mod.JoinMenu.OpenMenu();
            });
        }
    }
}
```

## WorldEntry.cs

```csharp
using System;
using System.Reflection;
using SFS;
using SFS.UI;
using SFS.World;
using SFS.WorldBase;
using UnityEngine;

namespace MyMod
{
    public static class WorldEntry
    {
        public static void Open()
        {
            try
            {
                Menu.loading.Open("Loading...");

                WorldSettings settings = new WorldSettings(
                    new SolarSystemReference(""),
                    new Difficulty { difficulty = 0 },
                    new WorldMode(WorldMode.Mode.Sandbox) { allowQuicksaves = false },
                    new WorldPlaytime(),
                    new SandboxSettings.Data());

                MethodInfo enterWorld = typeof(WorldBaseManager).GetMethod(
                    "EnterWorld",
                    BindingFlags.NonPublic | BindingFlags.Instance);

                if (enterWorld == null)
                    throw new MissingMethodException("WorldBaseManager.EnterWorld not found");

                enterWorld.Invoke(
                    Base.worldBase,
                    new object[]
                    {
                        null,
                        settings,
                        (Action)Base.sceneLoader.LoadHubScene
                    });
            }
            catch (Exception ex)
            {
                Menu.loading.Close();
                MsgDrawer.main?.Log("Enter world failed: " + ex.Message);
                Debug.LogError("[MyMod] Enter world failed: " + ex);
            }
        }
    }
}
```

## 关键坑

1. 不要用 Awake/Start 建按钮；Home_PC 会反复加载，必须挂 SceneHelper.OnHomeSceneLoaded。
2. 必须删除克隆按钮上的 TranslationSelector，否则文字会被翻译键覆盖回 Play。
3. 必须重设 holdEvent 和 clickEvent，避免继承原 Play 按钮监听。
4. 按钮要判重，否则返回主菜单会出现多个。
5. EnterWorld 是 private，只能反射调用，签名是 (WorldReference, WorldSettings, Action)。
6. EnterWorld 只负责把世界场景拉起来；要像联机一样同步远端火箭/玩家，还需要 ClientManager.LoadWorld、DivertLoading、LocalManager 整套逻辑。
7. 进入既有存档还要走 SavingCache/WorldLoader；本文只解决进入 Hub/新世界。
